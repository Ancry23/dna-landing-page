# DnA — Landing Page

Landing page per DnA, un'azienda immaginaria di divulgazione scientifica. Il progetto nasce da un brief aziendale (nome, mission, valori, pubblico di riferimento) da interpretare e trasformare in una pagina web completa.

## Il brief

DnA nasce dall'idea di due scienziati — un Dottore in Biologia Molecolare e una Dottoressa in Science and Management of Climate Change — con l'obiettivo di rendere la divulgazione scientifica più chiara e accessibile. Il progetto si articola in una rivista cartacea, una testata online e una sezione gratuita dedicata alle scuole primarie; ogni anno l'1% dei ricavi viene destinato alla ricerca scientifica, con l'ente beneficiario scelto dagli abbonati.

La pagina doveva rispondere a tre domande fondamentali: chi è l'azienda, cosa offre, perché un visitatore dovrebbe fidarsi o contattarla.

## Tecnologie utilizzate

- HTML5 semantico
- CSS3 (Flexbox, variabili CSS, media query)
- [Font Awesome](https://fontawesome.com/) per le icone
- [Google Fonts](https://fonts.google.com/) (Poppins)

Nessun framework o libreria JavaScript: solo HTML e CSS.

## Caratteristiche

- Design responsive, pensato per adattarsi anche a schermi più piccoli
- Contrasti e markup pensati per l'accessibilità (aria-label sui link social, attributi aria-hidden sulle icone decorative)
- Gerarchia delle informazioni chiara: identità aziendale, mission, offerta, impatto, contatti

## Come visualizzarlo

Non è richiesta alcuna installazione. Basta clonare il repository e aprire `index.html` nel browser:

```
git clone https://github.com/<tuo-username>/dna-landing-page.git
cd dna-landing-page
```

Poi apri `index.html` con il tuo browser preferito.
